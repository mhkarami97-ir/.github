## 🧭 درباره این سازمان

این سازمان محل نگهداری مجموعه‌ای از **وب‌اپلیکیشن‌های Progressive Web App (PWA)**، سایت‌های استاتیک و ابزارهای کوچک آموزشی/محتوایی است که به‌صورت مستقل توسط Mohammad Hossein Karami طراحی، توسعه و منتشر می‌شوند. هر ریپازیتوری معمولاً یک محصول مستقل با دامنه‌ی زیرمجموعه‌ی خودش روی `mhkarami97.ir` است؛ از پورتفولیوی شخصی و بلاگ فنی تا ابزارهای یادگیری لغت، تاریخ، الگوریتم و حتی پروژه‌های ایجنت هوش مصنوعی.

نقشه راه فنی مشترک بین اکثر پروژه‌ها:

- **PWA و Service Worker** برای تجربه آفلاین و کارایی بالا
- استقرار روی **GitHub Pages** و **Cloudflare** (Workers/Pages/D1/R2)
- **CI/CD** خودکار با **GitHub Actions**
- طراحی **واکنش‌گرا (Responsive)** برای موبایل و دسکتاپ
- استک اصلی: `HTML/CSS/JavaScript`، `Vue.js`، `React`، `.NET`، `Node.js`
